# Pattern Generator and Number Analyzer

A simple Python console application that allows users to:

- Generate star (`*`) patterns
- Analyze numbers in a given range
- Identify even and odd numbers
- Calculate the sum of numbers in a range

## Features

### 1. Pattern Generator
Creates a right-angled triangle star pattern based on the number of rows entered by the user.

Example:
```
*
**
***
****
```

### 2. Number Analyzer
Analyzes a range of numbers and:

- Checks whether each number is Even or Odd
- Displays the result
- Calculates the total sum of the range

Example:
```
Number 1 is Odd
Number 2 is Even
Number 3 is Odd
Sum of numbers from 1 to 3 is: 6
```

## Technologies Used

- Python 3

## How to Run

1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open terminal or command prompt.
4. Run the program:

```bash
python Logicbox.py
```
